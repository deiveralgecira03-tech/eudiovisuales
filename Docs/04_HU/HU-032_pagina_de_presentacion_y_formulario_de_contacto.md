# HU-032 — Página de Presentación y Formulario de Contacto

## Identificación

| Campo | Valor |
|---|---|
| ID | HU-032 |
| Título | Página de Presentación y Formulario de Contacto |
| Prioridad | Baja |
| Estado | Completado |
| RF asociado | RF-032 |

---

## Historia

*Como* Visitante interesado en Raccord,
*quiero* conocer el producto y escribir al equipo desde un formulario de contacto,
*para* solicitar información sin necesidad de tener una cuenta.

## Criterios de Aceptación

- La página de presentación es pública y no requiere inicio de sesión.
- Al enviar el formulario, el equipo de Raccord recibe un correo con mis datos.
- El texto que escribo se sanea antes de incluirse en el correo.
