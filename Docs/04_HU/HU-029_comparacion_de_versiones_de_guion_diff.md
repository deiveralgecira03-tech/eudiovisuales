## Historia

*Como* Script (continuista),
*quiero* comparar dos versiones del guion y ver resaltado qué cambió,
*para* comunicar rápidamente a los departamentos qué deben ajustar.

## Criterios de Aceptación

- El sistema resalta en rojo el texto eliminado, en verde el nuevo y en amarillo el modificado.
- La comparación se muestra lado a lado con desplazamiento sincronizado entre ambas versiones.
- El sistema genera un índice de páginas con cambios para navegar rápidamente.
- El usuario puede exportar un reporte de cambios en PDF con marca de agua.
