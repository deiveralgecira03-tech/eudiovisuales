# HU-023 — Subida y Control de Versiones de Guion

## Identificación

| Campo | Valor |
|---|---|
| ID | HU-023 |
| Título | Subida y Control de Versiones de Guion |
| Prioridad | Alta |
| Estado | Completado |
| RF asociado | RF-023 |

---

## Historia

*Como* Productor de Línea,
*quiero* subir el guion en PDF con su número de versión, fecha de emisión y estado,
*para* saber cuál es la versión vigente del guion y en qué etapa está.

## Criterios de Aceptación

- Puedo subir un PDF con nombre, descripción, número de versión único, fecha y estado (Borrador, Revisión, Aprobado, En Rodaje, Archivado).
- El sistema rechaza un número de versión repetido.
- La pantalla Guión lista los guiones con versión, fecha y estado.
- Solo Administrador y Director pueden subir guiones.
